### 1. Summary

The [Claude Platform & Solution Design](https://anthropic-partners.skilljar.com/path/claude-certified-architect-professional/claude-platform-solution-design/486647/scorm/2gvs1pi0tq0sq) readiness checkpoint consolidates the three architectural mappings required for enterprise AI architecture:

* **Behavioral Properties & Design Consequences:** Claude's probabilistic nature dictates specific architectural patterns. **Non-determinism** necessitates **evaluation frameworks**; static **knowledge boundaries** mandate **retrieval** (RAG) and **tools**; **context as a finite resource** forces explicit **context strategy**; and **confidence is not correctness** requires strategic **human-in-the-loop** (HITL) placement.
* **Platform Layers:** Enterprise architectures isolate user access, developer contracts, and execution environments into orthogonal layers: **Claude Code** operates as an **Entry Point**, **MCP** serves as a **Build-Time Interface**, and **AWS Bedrock** functions as a **Delivery Route**.
* **AI Primitives & Core Roles:** Solution components must be mapped strictly to their design primitive job: **Tools** (Act), **Subagents** (Isolate / parallelize), **Hooks** (Guarantee), and **Skills** (Package a procedure).

### 2. Clear & Simple Explanation

* **Behavior Drives System Design:** How the AI behaves determines how you build around it. Because AI answers vary across runs, you build automated tests (**evaluation frameworks**). Because AI doesn't know private or live data, you attach search tools and databases (**retrieval and tools**). Because memory is limited, you curate prompt payloads carefully (**context strategy**). Because AI can sound convincing even when wrong, humans must review high-risk actions (**human-in-the-loop**).
* **Three Platform Layers:** Keep three decisions separate: *Who interacts with it* (**Entry Point** like `Claude Code`), *How developers program it* (**Build-Time Interface** like `MCP`), and *Where traffic runs* (**Delivery Route** like `Bedrock`).
* **Primitive Matching:** Assign the right primitive to the job: **Tools** perform actions, **Subagents** isolate heavy tasks in parallel, **Hooks** guarantee hard safety rules in code, and **Skills** bundle repeatable procedures into versioned packages.

---

### 3. Preserve Technical Accuracy

Architectural design demands aligning model properties, platform abstractions, and execution primitives to prevent systemic failure modes:

* **Behavioral Constraints:** Address **non-determinism** via regression **evaluation frameworks**, overcome **knowledge boundaries** through dynamic **retrieval** and **tools**, optimize **context as a finite resource** via window token budgeting, and mitigate **confidence is not correctness** using **human-in-the-loop** guardrails.
* **Layer Decoupling:** Decouple developer CLI **Entry Points** (**Claude Code**) from open client-server protocol **Build-Time Interfaces** (**MCP**) and cloud infrastructure **Delivery Routes** (**AWS Bedrock**).
* **Primitive Specialization:** Leverage **Tools** for deterministic system actions, **Subagents** for context window isolation and parallelization, **Hooks** for unskippable event-driven policy enforcement, and **Skills** for encapsulated procedural logic.

### 4. Real-World Application

An enterprise fintech firm is building an automated credit application processing pipeline:

* **Addressing Model Behaviors:** To manage **knowledge boundaries**, the system queries applicant credit scores via external **tools**. To counteract **non-determinism**, output evaluation sets validate extraction accuracy in CI/CD. Recognizing **confidence is not correctness**, credit approvals over $50,000 are flagged via **human-in-the-loop** workflows.
* **Platform Layer Configuration:** Software engineers use **Claude Code** as their terminal **Entry Point** to develop integration logic, connecting via **MCP** as the **Build-Time Interface** to query internal loan databases, while hosting production traffic on **AWS Bedrock** as the compliance **Delivery Route**.
* **Primitive Integration:** The architecture deploys **Subagents** to parse bank statements in isolated contexts, uses **Hooks** to guarantee that unvalidated transfers are blocked before execution, and packages underwriting SOPs into versioned **Skills**.

**Question 3**

A multi-agent research pipeline is experiencing heavy latency and context window token exhaustion because a single primary reasoning agent processes five raw 100-page PDF reports sequentially. Which primitive should be used to resolve this performance bottleneck, and what one-word job does it perform?

A) Tools; to Act on external documents.

B) Skills; to Package a procedure for PDF parsing.

C) Subagents; to Isolate and parallelize raw document processing across separate context windows.

**Question 4**

A customer service platform powered by Claude frequently returns confident but factually incorrect explanations of legacy subscription policies. Which model property explains this failure mode, and what is the required architectural design consequence?

A) Context as a finite resource; design consequence is establishing a context window strategy.

B) Non-determinism; design consequence is deploying an evaluation framework.

C) Confidence is not correctness; design consequence is placing human-in-the-loop controls.

D) Knowledge boundary; design consequence is building a generator-verifier loop.

---

#### Answer & Explanation Key

* **Question 1 Correct Answer:** **B**
*Explanation:* Model completions are non-deterministic, and fluency does not equal correctness. Safety-critical constraints must be enforced deterministically using **Hooks** (job: Guarantee) in application code rather than relying strictly on system prompt instructions.
* **Question 2 Correct Answer:** **A**
*Explanation:* **Claude Code** is a developer CLI **Entry Point**, **MCP** is an open protocol **Build-Time Interface**, and **AWS Bedrock** is a managed cloud infrastructure **Delivery Route**.
* **Question 3 Correct Answer:** **C**
*Explanation:* **Subagents** perform the job to **Isolate / parallelize**, running heavy context tasks in separate execution windows to keep raw data tokens out of the primary reasoning loop and lower latency.
* **Question 4 Correct Answer:** **C**
*Explanation:* Fluency and an assured tone do not guarantee factual accuracy ("confidence is not correctness"). The primary architectural mitigation for high-risk policy generation is implementing **human-in-the-loop** (HITL) validation checkpoints.

### Key Technical Terms

* **Non-determinism:** The model behavior where identical inputs can yield varying output completions across runs, necessitating evaluation frameworks.
* **Knowledge Boundary:** The operational limit dividing static pre-trained training data from dynamic, private, or real-time context requiring retrieval or tools.
* **Context Strategy:** The deliberate design and token budgeting of inputs within the finite context window to manage performance and cost.
* **Human-in-the-Loop (HITL):** Strategic human oversight checkpoints placed at decision boundaries to counteract instances where model confidence does not reflect correctness.
* **Entry Point:** The interface wrapper through which users or developers interact with Claude (e.g., **Claude Code**, web/desktop apps).
* **Build-Time Interface:** The developer contract, library, or protocol used to programmatically integrate Claude (e.g., **MCP**, SDKs).
* **Delivery Route:** The managed cloud hosting environment where model inference traffic executes (e.g., **AWS Bedrock**, GCP Vertex AI).
* **Tools:** The primitive designed to **Act** by executing functions or fetching external state.
* **Subagents:** The primitive designed to **Isolate / parallelize** tasks within separate execution contexts.
* **Hooks:** The primitive designed to **Guarantee** unskippable event-driven policy enforcement in code.
* **Skills:** The primitive designed to **Package a procedure** into a reusable, versioned instruction and script asset.
