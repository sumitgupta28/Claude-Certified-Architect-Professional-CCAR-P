### 1. Summary

The [Claude Platform & Solution Design](https://anthropic-partners.skilljar.com/path/claude-certified-architect-professional/claude-platform-solution-design/486647/scorm/2gvs1pi0tq0sq) module details prompt caching mechanics, content ordering rules, and procedural packaging primitives for enterprise systems:

* **Caching Mechanics & Prefix Matching:** Prompt caching operates on strict prefix matching. Establishing an explicit **cache breakpoint** marks the boundary between fixed instructions (cacheable) and dynamic inputs (non-cacheable).
* **Content Ordering Rule:** Static content must strictly precede dynamic content. Placing variable per-request content (e.g., document payloads) ahead of fixed instructions alters the prefix on every API call, resulting in a 0% cache hit rate while continuously incurring cache write costs.
* **TTL & Amortization Economics:** Caching is an active design decision, not an automatic default. Small prefixes or low-volume API invocations fail to amortize the initial write overhead, increasing overall cost. Time-to-live (TTL) must align with prompt invocation frequency and update cycles.

* **Modular Prompt Libraries vs. Skills:**
  * **Modular Prompt Library:** A shared codebase collection of prompt fragments assembled dynamically in code. Ideal for single-team applications requiring lightweight, frequent customization.
  * **Skills (`SKILL.md`):** Formal, versioned, self-contained artifacts packaging instructions, metadata, and optional executable scripts. Designed for cross-team distribution requiring governance, approvals, and rollback controls.


* **Architectural Risk & Control:** Unmanaged prompt sharing causes **prompt drift**—quiet, unmonitored behavioral divergence across microservices. Versioned Skills serve as the primary control to maintain consistent execution.

### 2. Clear & Simple Explanation

* **Put Fixed Rules First:** Caching only works if the beginning of your prompt stays identical across API calls. Always place fixed system instructions first and variable user data last.
* **Caching Isn't Always Cheaper:** Writing to a cache costs extra up front. If a prompt is rarely run or has a small instruction block, caching will cost more money than it saves because you won't get enough cache hits to offset the initial write charge.
* **Prompt Libraries vs. Skills:** Use a prompt library when software developers need flexible code snippets within a single app. Use a Skill (`SKILL.md`) when a complete, multi-step process must be packaged, versioned, and shared across different teams without risking unauthorized edits.
* **Stop Prompt Drift:** When teams copy and paste prompts across services, small edits cause systems to behave differently over time. Centralized, version-controlled Skills keep all systems aligned.

### 3. Real-World Application

**Scenario: Multi-Tenant Legal Document Compliance Engine**
An enterprise platform uses Claude to analyze commercial contracts across four internal divisions, processing tens of thousands of documents daily.

* **Architectural Implementation:**
* **Cache Prefix Optimization:** System architects structure the prompt to place a 15,000-token legal compliance framework and target JSON schema at the top, setting a cache breakpoint directly before the variable contract text. This ordering yields a 92% cache hit rate, lowering API spending by over 65%.
* **Skill Packaging (`SKILL.md`):** The compliance analysis workflow is packaged as a centralized **Skill** containing a `SKILL.md` specification and automated schema verification scripts.
* **Cross-Team Governance:** Instead of allowing individual engineering teams to copy-paste system prompt strings into separate codebases (which risks prompt drift), all four divisions pull the versioned Skill artifact. Updates to compliance policies are released as new Skill versions, guaranteeing uniform, auditable behavior across all backend services.

#### Answers and Explanations

* **Question 1 Correct Answer:** B
* **Explanation:** Caching relies on matching a stable prefix. Placing variable content (`<document>`) ahead of fixed instructions modifies the prefix on every call, causing a 0% cache hit rate while continuously incurring write overhead charges.


* **Question 2 Correct Answer:** C
* **Explanation:** A Skill (`SKILL.md`) is a formal, versioned unit packaging instructions, scripts, and governance controls, making it the correct primitive for cross-team procedural distribution requiring approval and rollback management.


* **Question 3 Correct Answer:** B
* **Explanation:** Caching carries a write overhead cost. For low invocation volumes or small prefix sizes, the initial cost to write to the cache is never recovered through hit savings, producing a net cost increase.


* **Question 4 Correct Answer:** B
* **Explanation:** Unmanaged copying of prompt text leads to prompt drift—divergent behavior across microservices. Centralizing and versioning procedures via Skills or managed repositories eliminates drift.

### Key Technical Terms

* **Cache Breakpoint:** The designated explicit boundary in a prompt separating stable, reusable content from dynamic per-request content.
* **Prefix Matching:** The underlying caching mechanism that compares incoming prompt prefixes against previously cached tokens to determine cache hits.
* **Write Overhead:** The initial financial and performance cost incurred when writing prompt tokens into the cache layer.
* **Amortization:** The process of offsetting initial cache write costs through repeated subsequent cache hits over time.
* **Prompt Drift:** The gradual, ungoverned divergence in system behavior resulting from unmanaged copy-pasting and localized editing of prompt text.
* **Modular Prompt Library:** A software repository of reusable prompt fragments and templates assembled programmatically within individual application codebases.
* **Skill (`SKILL.md`):** A formal, versioned, and governed packaging artifact containing instructions, metadata, and optional execution scripts for repeatable cross-team procedures.
* **TTL (Time-To-Live):** The configured duration for which a cached prompt prefix remains active and accessible in memory before expiring.
